# ChatGPT and Codex Integration

The starter installs a root `AGENTS.md`. Repository-aware Codex workflows use AGENTS files as persistent instructions within their directory scope.

For ChatGPT Projects, `CHATGPT_PROJECT_KNOWLEDGE.md` is designed to be kept in Project sources along with the repository or evidence files. Project files and project instructions provide continuing context across chats.

There is no universal mechanism by which every ordinary ChatGPT chat automatically reads a ZIP sitting on a phone or in an unrelated filesystem. Automatic repository behavior begins after the starter is extracted/installed into the repository or its knowledge file is added to the relevant ChatGPT Project.
