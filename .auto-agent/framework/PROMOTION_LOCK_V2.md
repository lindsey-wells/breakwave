# Promotion Lock V2

A green promotion lock records the exact project, repository, baseline commit, authoritative plan file and SHA-256, control commit, ordered stage commits, final combined commit, final tree hash, payload hashes, evidence ZIP name and SHA-256, validation branch, workflow name, workflow run ID, workflow job ID, conclusion, completion timestamp, and approval policy.

A red or verification-unavailable result may create evidence and pause state, but never a green promotion lock.
