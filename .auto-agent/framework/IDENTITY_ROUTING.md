# Project-Bound Identity Routing

Before mutation or push, verify the active GitHub account is `lindsey-wells`, the repository is `lindsey-wells/breakwave`, the remote normalizes to that repository, the branch is `main`, and HEAD matches the approved baseline or verified production prefix.

A temporary inability to query GitHub is verification unavailable. It is not permission to continue and not a CI failure.

Never switch to another project identity silently. Never reuse ForgePhone or Breakout Addiction credentials, repositories, branches, product rules, or payloads in BreakWave.
